4-2 光的反射與面鏡成像

沒有光進入眼睛 → 看不到
發光體：光 → 進入眼睛 → 看見
非發光體：光源 → 物體反射 → 進入眼睛 → 看見
沒有光進入眼睛，就看不見。

中心思想
  1. 入射線、反射線分居法線兩側
  2. 入射角 = 反射角
  3. 入射線、法線、反射線在同一平面
  4. 光路可逆
這個位置看不到像
平面鏡成像：物與像對稱於鏡面、物距＝像距、大小相等、是虛像（延長線交點，沒有真實光線，接不到）。

④ 凹面鏡、凸面鏡

①平行主軸 → 過焦點 F
②過焦點 → 平行主軸
③射向鏡頂 → 對稱主軸
①平行主軸 → 反射線延長線過虛焦點 F
②射向鏡頂 → 對稱主軸
凹面鏡會聚光；凸面鏡使光發散。
